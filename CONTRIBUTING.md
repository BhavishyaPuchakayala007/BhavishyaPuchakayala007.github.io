# Contributing

Thanks for stopping by. This is a personal portfolio, so it isn't a typical open-source project, but there are still good ways to get involved.

## Report a bug

Something broken, slow, or weird on a particular device or browser? Open an issue with the "Bug report" template and include:

- what you expected and what happened
- your browser, device and screen size
- a screenshot or screen recording if you can

## Suggest an improvement

Ideas for accessibility, performance, or making the code easier to follow are very welcome. Open an issue first so we can talk it through, then send a pull request:

1. Create a branch from `main`.
2. Keep the change focused on one thing.
3. Run `bun run build` (or `npm run build`) to make sure it still builds.
4. Describe what you changed and why, with a screenshot for anything visual.

Changes to the story, copy or design of the site are Bhavishya's call, so please open an issue before working on those.

## Build your own

The code is MIT-licensed, so you're free to build on it. It started from [Nidhi Prajapati's portfolio](https://www.somehowliving.tech), which is the best place to fork from. The story, the words, the robot hand and the project drawings here aren't part of that license, so please replace them with your own (see `LICENSE`).

## Be kind

Be respectful and constructive. That's it.
